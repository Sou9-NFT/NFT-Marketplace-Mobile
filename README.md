# Sou9 NFT

Sou9 NFT is a modern NFT Marketplace mobile application built with Flutter and FlutterFlow. The app allows users to browse, buy, sell, and trade NFTs in a seamless and intuitive interface.

## Features

- Browse trending and featured NFTs
- Buy, sell, and trade NFTs securely
- User authentication and profile management
- NFT detail pages with images and metadata
- Search and filter NFTs by category or creator
- Integration with Firebase for backend services
- Responsive design for Android and iOS

## Getting Started

### Prerequisites

- [Flutter SDK](https://flutter.dev/docs/get-started/install) (stable channel)
- [Dart SDK](https://dart.dev/get-dart)
- [Firebase CLI](https://firebase.google.com/docs/cli) (for backend integration)
- An IDE such as VS Code or Android Studio

### Installation

1. Clone the repository:

   ```sh
   git clone https://github.com/yourusername/NFT-Marketplace-Mobile.git
   cd NFT-Marketplace-Mobile
   ```

2. Install dependencies:

   ```sh
   flutter pub get
   ```

3. Set up Firebase:
   - Add your `google-services.json` (Android) and `GoogleService-Info.plist` (iOS) files to the respective directories.
   - Update Firebase configuration as needed in the `firebase/` directory.

4. Run the app:

   ```sh
   flutter run
   ```

## Project Structure

- `lib/` - Main application code
- `assets/` - Images, fonts, and other assets
- `firebase/` - Firebase configuration and functions
- `android/` & `ios/` - Platform-specific code
- `test/` - Unit and widget tests
